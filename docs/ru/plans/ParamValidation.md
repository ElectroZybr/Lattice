# Проверка параметров при записи

Параметр объявляет правила (`range`, `choices`, `maxLength`) или свой сеттер; запись
возвращает отказ с подробностями (код, сообщение, участок ввода, допустимое), и инструменты
(CLI, GUI, сериализация) показывают его одинаково. Правила — заодно метаданные для GUI.
Потребитель — LatticeLab (CLI, Serializer, форма сосуда строкой).

## Ядро

- [ ] `ParamRejection` (код, сообщение, участок текста `[begin, end)`, `min`/`max`, допустимые значения) и `ParamResult`
- [ ] `param(...)` возвращает `ParamBuild` (приводится к `ExportId`): `.range(min, max)`, `.choices({...})`, `.maxLength(n)` — проверка и метаданные
- [ ] Свой сеттер `param(name, &T::field, &T::set)`: разобрать и применить или отказать — в потоке владельца (`executeOn`)
- [ ] Путь записи: тип → правила → сеттер → запись → уведомление; `ExportsView::set` возвращает `ParamResult`, отказ не меняет поле и не уведомляет
- [ ] `ExportsView::rules(id)` — правила параметра для инструментов
- [ ] Тесты: диапазон, выбор, свой сеттер в чужом потоке, отказ без записи и уведомления
