# Проверка параметров при записи

Параметр объявляет правила (`range`, `choices`, `maxLength`) или свой сеттер; запись
возвращает отказ с подробностями (код, сообщение, участок ввода, ожидаемое), и инструменты
(CLI, GUI, сериализация) показывают его одинаково. Правила — заодно метаданные для GUI.
Потребитель — LatticeLab (CLI, Serializer, форма сосуда строкой). Описание —
[композиция](../articles/Composition.md#правила-и-свой-сеттер-параметра), цена — бенч
`Lattice.bench Exports`.

## Ядро

- [x] `ParamRejection` (код, сообщение, участок `[begin, end)`, ожидаемое) и `ParamResult` — один указатель; диапазон и выбор — в `rules(id)`, не в отказе
- [x] `param(...)` возвращает `ParamBuild` (приводится к `ExportId`): `.range(min, max)`, `.choices({...})`, `.maxLength(n)` — проверка и метаданные
- [x] Свой сеттер `param(name, &T::field, setter)` — метод или вызываемое, возвращает `ParamResult`; в потоке владельца (`executeOn`)
- [x] Путь записи: тип → правила → сеттер → запись → уведомление; `Exports::set`, `ExportsView::set` и сырой `ResolvedExport::set` возвращают `ParamResult`, отказ не меняет поле и не уведомляет
- [x] `ExportsView::rules(id)` — правила параметра для инструментов
- [x] Тесты: диапазон, выбор, длина, тип, сырой сеттер, свой сеттер в чужом потоке, отказ без записи и уведомления
- [x] Раздел с примером в [композиции](../articles/Composition.md)

## Цена

- [x] Бенч `Exports`: запись напрямую, сырая, через исполнитель, через поток владельца; с правилами, отказ, свой сеттер; регистрация и куча на параметр
- [x] Раскладка: `Export` + `Param` в своём массиве, плоский индекс имён без второй копии имени, состояние только у параметров с правилами, сеттером или потоком — 256 → 104 байта на параметр
- [x] Уведомления без аллокаций; отписка во время уведомления
- [x] Простая запись в поток владельца — `post` без ожидания (7,5 мкс → 0,14 мкс); отложенные записи доходят до объекта до уничтожения (`settle`)
- [x] Быстрый путь без исключений и канареек стека, отказы — холодные функции: прямая запись 3,6 → 4,2 нс (возврат `ParamResult`), с `range` — 6 нс
