# История бенчмарков (`lbm`)

Репозиторий результатов, статистика, поиск сдвигов, инструмент `lbm`. Проект — [BmHistory](../articles/BmHistory.md).

## BmRunner

- [x] `RunResult`: окружение (SysInfo, BuildInfo) + результаты бенчей с семплами, анализом и `Compare`; запись в TSV (длинный вид, стабильная сортировка, фиксированная точность)
- [x] `Benchmarks::main(argc, argv)`: `--list`, `--filter <маска>`, `--tsv <файл>`; запуск группы с `Compare`; наборы LatticeLab переходят на него
- [x] Семплы в результатах стадии (сейчас в `StageResult` только сводка)
- [x] Исправить старую ошибку: `name`/`group` в `BenchResult` ссылаются на строки бенча — копии

## BmHistory

- [x] Обёртка `git` (запуск процесса, ошибки с выводом git); `cat-file --batch` для чтения многих версий
- [x] Чтение TSV результатов (свой разбор под известные колонки)
- [x] Репозиторий результатов: создание, раскладка `<machine>/<suite>.tsv` и `machine.toml`, слияние частичного запуска (колонка `measured`), коммит запуска с трейлерами
- [x] Отпечаток машины и окружение кода (sha, dirty) по пути набора и конфигурации
- [x] Чтение: запуск по rev, история файла бенча, трейлеры коммитов
- [x] Baseline-теги
- [x] Статистика: отношение медиан, bootstrap-интервал, Манна–Уитни, шум; сравнение `fixed`/`per` и `N*`
- [x] История: точки сдвига ряда, связь с коммитом кода

## `lbm`

- [x] Команды `list`, `run`, `log`, `show`, `compare`, `history`, `regressions`, `tag`
- [x] `lbm.toml`: наборы, репозитории кода, пороги (необязателен)
- [x] Поиск наборов через xmake (`<Name>.bench`), сборка перед запуском
- [x] Установка: `xmake install-lbm` → `~/.local/opt/lattice-benchmarks`, ссылка в `~/.local/bin`
- [ ] Пакет xmake `lattice-benchmarks` для проектов, которые хотят `lbm` зависимостью
- [x] Таблицы вывода, код возврата для CI (`compare`, `regressions`)
- [ ] Вывод `--tsv`/`--json` для других инструментов
- [ ] Windows: запуск процессов (`fork`/`posix_spawn` сейчас только POSIX)
- [ ] Тесты разбора `lbm.toml`
