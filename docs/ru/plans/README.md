# Планы

Список крупных блоков. Подробный план блока с чекбоксами — в своём файле рядом, в едином
формате: цель и ссылки на проект, этапы с пунктами. Готовый блок отмечается и переносится в
«Готово» одной строкой итога. Как вести планы — [правила](../Rules.md#документация-и-планы).
