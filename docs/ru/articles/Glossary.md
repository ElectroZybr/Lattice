# Термины

| Термин | Что это |
| --- | --- |
| **Узел** | Элемент дерева: объект, которым владеет дерево, с именем, типом и id (`#30`). |
| **Ветка** | Узел с поддеревом; удаляется целиком. Пакет собирает свою ветку. |
| **Пакет** | Разделяемая библиотека с `compose` (и необязательно `configure`) и метаданными `lattice_package`. |
| **Композиция** | Функция `compose`: создание объектов, размещение в дереве, связи. Единственное место пакета, знающее о Lattice. |
| **configure** | Повторяемое связывание с текущим деревом: наборы детей, выбор из Context. Вызывается после `compose` и при изменениях. |
| **Blueprint** | Описание, как собрать узел (тип или композиция); blueprint пакета называется по его `id`. |
| **API** | Интерфейс, под которым объект виден в дереве: `emplace<Impl, API>`. |
| **Handle** | Ссылка на объект узла во время композиции (`ObjectBuild`) или работы (`Ref`). |
| **Зависимость** | Связь «потребитель — поставщик» через аргумент конструктора; удаление поставщика завершает потребителей. |
| **Context** | Выбор общих ролей по веткам: кандидаты, явный выбор, неоднозначность — ошибка. |
| **Focus** | Явный выбор экземпляра в Context; во время работы — handle на выбранное. |
| **mount** | Получить общий ресурс через Context с зависимостью от него. |
| **Снимок** | Результат запроса в `compose` (`children`, `require`): сам не обновляется. |
| **Слот** | Выбираемая реализация API: варианты — реализации из пакетов (`Implementation`), собрана одна; выбор — `select` или параметр выбора; смена — пересборка слота. |
| **Конвейер** | `Pipeline`: стадии-дети узла (`PipelineAPI`) выполняются по порядку; группы вкладываются. |
| **Сервис** | Объект с долгим циклом (`run`/`requestStop`): свой поток или host. |
| **Экспорт** | Параметр (`param`) или действие (`action`) объекта; идентичность — (владелец, имя). |
| **Исполнитель экспортов** | Очередь, через которую идут экспорты объекта (`executeOn`) — поток-владелец состояния. |
| **retire** | Завершение узла: экспорты снимаются, хуки вызываются, удаление — когда готов. |
| **maintain** | Обслуживание runtime на host-потоке: удаление, `configure`, хуки `onMaintain`. |
| **host-поток** | Поток, вызывающий `maintain`; только в нём меняется дерево и Context. |
